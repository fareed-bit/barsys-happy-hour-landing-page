# Local media

The `events` subfolder contains the supplied real Barsys event media prepared for
this local preview. See `../reference/event-asset-manifest.json` for provenance.
All working event video files are silent H.264 MP4s. Images used by the page are
local WebP/JPEG/PNG assets. No font files are bundled.

The other brand and drink images came from the preceding V2 project. They are
retained for menu cards and brand identification, not presented as event evidence.
