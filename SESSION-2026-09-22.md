## Blockers found by testing Collins as a customer — NOT fixed

1. **Clamped to three drinks.** `collins-events-staging` has an operator menu set (the kiosk
   "tonight's menu"). Every answer is held to Old Fashioned / Negroni / Spicy Margarita.
   Asked for a five-drink menu it says "I've only got three on tap tonight." **This is what
   guests see on the public site right now.** Clearing that menu is the single highest-value
   fix and needs no code.
2. **Passing `context.menu` does not reliably override it.** Tested: it picked up two drinks
   from a supplied list, then invented a non-existent drink called "the Fixed", and still
   capped at three. Do not ship this as the fix.
3. **No HappyHour domain knowledge.** It advised "find a spot in New York that can handle a
   private booking" — the product is that Barsys brings the bar to your office. It also
   refuses package/pricing questions. Earlier I tried grounding it with real figures from
   config.js: it called a service package a machine ("two bottles and a drip tray") and
   invented a contact address (hello@barsys.com; ours is fareed@barsys.com). Client-side
   prompt stuffing cannot fix this — it needs a domain hook on `/api/collins/ask` in
   `barsysindia/collins-events`. A test pins that finding so it is not rediscovered.

## Other repo: barsysindia/collins-events

**PR #20 open, CI green** — https://github.com/barsysindia/collins-events/pull/20
Moves the image off end-of-life Node 18 (EOL 2025-04-30) to Node 22 LTS and stops shipping
npm in the runtime image. Measured with Trivy on the real built image:

| | Critical | High |
|---|---|---|
| node 18 (today) | 5 | 47 |
| node 22 | 3 | 21 |
| node 22, npm removed (the PR) | 2 | 11 |

It will **not** make the NeuVector gate pass — the gate trips on any high, and the last 11
are entirely the Next 14.2 tree. `next@14.2.35` is the newest on that line. **Next 15 is not
enough**: 15.5.9 still pins the vulnerable postcss 8.4.31; only 16.3.5 ships postcss 8.5.23.
It has to be Next 16, which needs Node ≥20.9 — satisfied by this PR.
